Versioned folder markers

Seven ways to mark a folder that keeps versions. The current clock is included for comparison; the rest drop the dark puck or replace the metaphor. Shown at grid, list, path-bar and sidebar sizes.

Large 96 px grid Medium 48 px list Small 32 px list Inline 14 px path bar / sidebar

All badges sit at the folder’s lower-right, where the app puts the current clock. The stacked-folder option has no badge at all in large sizes; it uses a small layer glyph inline. The layer-stack and hourglass options use their glyphs everywhere. The ribbon uses a bookmark ribbon instead of an emblem.

At the app’s 16 px list zoom, any corner badge covers most of the folder. Whichever option wins should either hide the badge at that size or switch to a simplified mark.
